Sales Data Analysis
About
This project is done using Jupyter Notebook.
We use a sales dataset to perform data cleaning and data analysis.

Requirements
Make sure you have the following libraries installed before running the code:
pip install pandas matplotlib numpy seaborn
Steps Performed
Load the sales data (CSV file)

Clean the data:
Remove missing values
Fix column names and data types
Remove duplicates

Analyze the data:
Total sales
Sales by product and region
Monthly trends

Visualize using:
Bar charts
Line graphs
Heatmaps

How to Run
Open the project in Jupyter Notebook
Run each cell step by step
View the results and charts
